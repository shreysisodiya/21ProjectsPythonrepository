Introduction 
- The goal of this project is to apply the powerful technique of transfer learning for an image classification task. We will be working with the Oxford Flowers 102 dataset, a collection of 102 different types of flowers. To accomplish this, we will use three different pre-trained Convolutional Neural Network (CNN) models that have been trained on the massive ImageNet dataset. 


These models are:
- ResNet50: A deep residual network known for its skip connections that help with training very deep networks.

- VGG16: A simpler, but effective, deep network architecture with a consistent design of convolutional and max-pooling layers.

- MobileNetV2: A lightweight and efficient model designed for mobile and em
bedded vision applications, which uses depthwise separable convolutions.

By leveraging these pre-trained models, we can benefit from the features they have already learned from millions of images and adapt them for our specific flower classification task.
